# Unscroll PC

**A calm computer for curious kids. No feeds, no algorithms.**

Unscroll turns an old laptop, netbook or Raspberry Pi into a calm listening and discovery
computer for kids: music, audiobooks, podcasts, radio and e-books, an AI buddy with clear
limits, puzzles and a private writing nook. Everything lives in one keyboard-driven terminal
app, with no desktop and no web browser.

**No feeds, recommendations, autoplay, likes, streaks or addictive games.** The child chooses,
from a collection the parents put together. Even the AI buddy only speaks when spoken to,
keeps conversations short, and helps the child think instead of thinking for them.

The project started on an old Asus Eee PC, hence the "PC" in the name.

## Principles

1. **No feeds, no algorithms.** No "recommended for you", no endless scrolling, no autoplay.
2. **No addictive games, points or streaks.** Nothing rewards "just a little longer". Calm puzzles such as sudoku and chess problems are fine.
3. **Quiet evenings.** Quiet time is part of the system: after bedtime only reading and an audiobook with a sleep timer remain (configurable).
4. **Honest.** The child knows what parents can see. The writing nook is private.
5. **Standalone.** Works on its own with speakers attached. Connecting to a NAS or Music Assistant is possible, not required.
6. **Light.** Must run smoothly on a 32-bit netbook with 1 GB of memory.

### Spotify without the algorithm

- **No autoplay.** Unscroll controls the queue: an album plays and then stops. Autoplay is off in librespot.
- **No recommendations.** The app never asks for "Made for you", Daily Mix, Discover Weekly or song radio.
- **Approved albums and playlists only.** Searching all of Spotify is off by default, because even the order of search results is decided by an algorithm.
- **Tip for parents:** give the child their own Spotify profile and don't approve mixes generated by Spotify. Spotify still learns from listening; you won't see that on Unscroll, but you will in the official app.

## Suitable devices

Anything that runs Debian 12. Intended for:

| Device | Architecture | Notes |
|---|---|---|
| Asus Eee PC and other netbooks | 386 (32-bit) | Where this project started. 1 GB of memory is enough. |
| Old laptops (ThinkPad, Dell, HP) | amd64 | Often available second-hand for very little |
| Ex-school Chromebooks with Intel | amd64 | Flash MrChromebox firmware first |
| Raspberry Pi 4 / 5 with screen and keyboard | arm64 | Raspberry Pi OS Lite (Bookworm) |
| Raspberry Pi 400 / 500 | arm64 | A computer inside a keyboard: just add a screen |
| Handheld Pi terminals (uConsole, DevTerm) | arm64 | A real cyberdeck |

## Installing

1. Install a minimal **Debian 12** (only "SSH server" and "standard system utilities", no desktop).
   For old 32-bit netbooks use the [i386 netinst image](https://cdimage.debian.org/cdimage/archive/latest-oldstable/i386/iso-cd/).
2. Put this repository on the device and run as root:
   ```bash
   sudo bash install.sh
   ```
3. Set the PIN, quiet time and secrets locally with the parent helper, then reboot:
   ```bash
   sudo unscroll-ouder
   ```

**No internet on the device?** Use the offline bundle: Debian packages for 32-bit plus the app
(about 230 MB). Install Debian with "do not configure the network", copy the bundle to a USB
stick and run `sudo bash install.sh` from the bundle folder. The installer detects the `debs`
folder and does not use the internet. Build it yourself with `scripts/make-offline-bundle`
(on any Linux machine with apt) or ask in the issues.

After booting, the child account logs in automatically and the app starts full screen
(`cage` with the `foot` terminal). There is no desktop, no browser and no free shell.

## Updates

- **Releasing a new version:** bump the number in `VERSION` and push to `main`. GitHub Actions runs the tests, builds the app for 386, amd64, arm64 and arm (with a `sha256` file per binary) and creates the release.
- A number with a dash (`0.2.0-test`) becomes a pre-release. It only goes to devices with `KANAAL="test"` in `/etc/unscroll/update.conf`.
- Devices check for a new release every 15 minutes (`unscroll-update.timer`), verify the checksum and that the new binary starts, then install it. The previous version is kept. The new version is active after the next restart of the app (or a reboot).
- The scripts (session, updater, parent helper) come along in a checksummed `unscroll-scripts.tar.gz` and are installed with the app (from v0.2.0 on).
- If the repository is private, put a fine-grained read-only token in `/etc/unscroll/geheimen.env` (the parent helper asks for it).

## Listening (phase 1)

Press `1` for Listen and `Tab` to switch between Music, Audiobooks, Podcasts and Radio.
Everything plays through `mpv` without video. There is no autoplay: an album plays to the end and then it is quiet.

| Source | Needs | Set up with |
|---|---|---|
| Music | [Navidrome](https://www.navidrome.org/) with its own user for the child | `sudo unscroll-ouder` (address, user, password) |
| Audiobooks and podcasts | [Audiobookshelf](https://www.audiobookshelf.org/) with an account for the child, so the progress is theirs | `sudo unscroll-ouder` (address and API token or API key) |
| Radio | nothing: NPO Radio 1, 2, 3FM, Klassiek and BBC World Service are built in | your own list under `radio:` in `/etc/unscroll/ouders.yaml` |

Keys: `↑ ↓` choose, `Enter` open or play, `Backspace` back, `/` search, `space` pause, `x` stop,
`n` `p` next or previous track, `← →` 30 seconds back or forward (on the radio: tune the dial),
`s` sleep timer (15, 30, 45, 60 minutes), `+ -` volume up to the parents' maximum.

During quiet time only audiobooks stay available (if `luisterboek_mag` is on), with a sleep timer
of 30 minutes that starts by itself. Music, radio and podcasts stop when quiet time begins.

Parents can pause quiet time in parent mode (`8`, then `o` and the PIN): `t` 30 minutes, `u` 2 hours,
`m` until tomorrow morning, `x` until switched back on, `a` back on. Parent mode switches itself off
after 10 minutes without a key press.

## Spotify without the algorithm (phase 3)

Needs Spotify Premium (Duo works; with Family the child gets its own account and its listening
does not mix with yours). Sound comes from [librespot](https://github.com/librespot-org/librespot),
a Spotify Connect speaker that the updater installs (`/usr/local/bin/librespot`, not for 32-bit ARM).
The app controls it through the Spotify Web API and only plays what you approved.

Once, on a phone or computer:
1. Create an app at [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard), tick Web API,
   and add the redirect URI `http://127.0.0.1:8898/callback`. Copy its Client ID.
2. On the device run `sudo unscroll-ouder`, enter the Client ID, log in (the helper shows a link;
   you end up on a page that does not load, copy that address back), and link the speaker the same way.
   Use the same Spotify account for both.
3. Approve albums and playlists: add their links under `spotify: goedgekeurd:` in `/etc/unscroll/ouders.yaml`.

With `zoeken: true` (asked by `sudo unscroll-ouder`) the child can also search artists and albums,
browse all albums of an artist and keep favourites (`f`), without recommendations, radio or autoplay.
Explicit songs and artists under `geblokkeerd:` stay out; parents see searches and listens of the past
week in parent mode (`w` on the Spotify list).

In the app: `1` Listen, `Tab` to Spotify. An approved album or playlist plays in order and then stops.
If anything else starts playing on the speaker (autoplay, or someone taking it over from another device),
the app pauses it.

## The AI buddy (phase 4)

Press `3` (the tab carries the buddy's name). Set the API key and choose the model with `sudo unscroll-ouder`; create it at
[console.anthropic.com](https://console.anthropic.com) and set a monthly spend limit there.
The buddy answers with `claude-opus-5-5` by default and every question and answer is checked by
`claude-haiku-5-5`; both can be changed under `maatje:` in `/etc/unscroll/ouders.yaml`
(for example `model: "claude-sonnet-5-5"` to spend less).

The buddy is a helper, not a friend: it only speaks when asked and helps the child think
instead of thinking for them. Limits depend on the kind of use:

| Mode | How | Default limit |
|---|---|---|
| Homework coach and quizzing | A session about one assignment: try first, hints in steps, a worked example with different numbers, ending with "what did you learn?" | 2 sessions a day, 40 turns per session |
| Write a story together | Take turns writing, saved in the writing nook | 1 session a day |
| Free questions | Curiosity: "how does it work?" | 15 a day |
| Overall | | 45 minutes a day, a break after 20 minutes, closed during quiet time |

Safety: personal details (e-mail, phone, address, postcode, IBAN, the child's own name) are filtered
out on the device before anything is sent, every question and answer gets a second suitability check,
heavy topics are referred to the parents (with an ntfy notification that does not include the question),
and `Tab` on an empty line asks "is this right?", which teaches that AI can be wrong.

Parents see the questions of the past week in parent mode: open the buddy tab and press `w`.
Stories written together are saved in the writing nook (`~/.local/share/unscroll/verhalen`);
parents only see that a story was written, not the story itself.

Parents set the limits in `/etc/unscroll/ouders.yaml` (section `maatje`; 0 means no limit).
Stories can be continued later: choosing "Story together" again offers the earlier stories.
Parents set the key and model with `sudo unscroll-ouder`. The defaults and the buddy's instructions
are part of the app and are tuned through updates as we learn from real use.

## Passwords and keys

**Secrets never go into this repository.** PIN, passwords, usernames, tokens and API keys are
set locally on the device with the parent helper:

```bash
sudo unscroll-ouder
```

It writes to `/etc/unscroll/ouders.yaml` and `/etc/unscroll/geheimen.env` (readable only by
root and the app). Git only contains example files with empty values. GitHub Actions checks on
every push that no real settings or keys ended up in the repository.

## Development

```bash
cd app
go test ./...
go run .                      # runs in your own terminal
UNSCROLL_OUDERS=../config/ouders.example.yaml go run .
CGO_ENABLED=0 GOOS=linux GOARCH=386 go build -o unscroll .
```

The app is written in Go with [Bubble Tea](https://github.com/charmbracelet/bubbletea) and
[Lip Gloss](https://github.com/charmbracelet/lipgloss), so it ships as a single small binary
that runs well on old 32-bit hardware. Some file names and code identifiers are still Dutch,
since the project started in a Dutch family; translations of the app are welcome.
