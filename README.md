# Unscroll PC

**A calm computer for curious kids. No feeds, no algorithms.**
*Nothing pulls at you. You pull.*

Unscroll turns an old laptop, netbook or Raspberry Pi into a calm listening and discovery
computer for kids: music, audiobooks, podcasts, radio and e-books, an AI buddy with clear
limits, puzzles and a private writing nook. Everything lives in one keyboard-driven terminal
app, with no desktop and no web browser.

**No feeds, recommendations, autoplay, likes, streaks or addictive games.** The child chooses,
from a collection the parents put together. Even the AI buddy only speaks when spoken to,
keeps conversations short, and helps the child think instead of thinking for them.

The project started on an old Asus Eee PC, hence the "PC" in the name.

## Principles

1. **No feeds, no algorithms.** No "recommended for you", no endless scrolling, no autoplay.
2. **No addictive games, points or streaks.** Nothing rewards "just a little longer". Calm puzzles such as sudoku and chess problems are fine.
3. **Quiet evenings.** Quiet time is part of the system: after bedtime only reading and an audiobook with a sleep timer remain (configurable).
4. **Honest.** The child knows what parents can see. The writing nook is private.
5. **Standalone.** Works on its own with speakers attached. Connecting to a NAS or Music Assistant is possible, not required.
6. **Light.** Must run smoothly on a 32-bit netbook with 1 GB of memory.

### Spotify without the algorithm

- **No autoplay.** Unscroll controls the queue: an album plays and then stops. Autoplay is off in librespot.
- **No recommendations.** The app never asks for "Made for you", Daily Mix, Discover Weekly or song radio.
- **Approved albums and playlists only.** Searching all of Spotify is off by default, because even the order of search results is decided by an algorithm.
- **Tip for parents:** give the child their own Spotify profile and don't approve mixes generated by Spotify. Spotify still learns from listening; you won't see that on Unscroll, but you will in the official app.

## Suitable devices

Anything that runs Debian 12. Intended for:

| Device | Architecture | Notes |
|---|---|---|
| Asus Eee PC and other netbooks | 386 (32-bit) | Where this project started. 1 GB of memory is enough. |
| Old laptops (ThinkPad, Dell, HP) | amd64 | Often available second-hand for very little |
| Ex-school Chromebooks with Intel | amd64 | Flash MrChromebox firmware first |
| Raspberry Pi 4 / 5 with screen and keyboard | arm64 | Raspberry Pi OS Lite (Bookworm) |
| Raspberry Pi 400 / 500 | arm64 | A computer inside a keyboard: just add a screen |
| Handheld Pi terminals (uConsole, DevTerm) | arm64 | A real cyberdeck |

## Installing

1. Install a minimal **Debian 12** (only "SSH server" and "standard system utilities", no desktop).
   For old 32-bit netbooks use the [i386 netinst image](https://cdimage.debian.org/cdimage/archive/latest-oldstable/i386/iso-cd/).
2. Put this repository on the device and run as root:
   ```bash
   sudo bash install.sh
   ```
3. Set the PIN, quiet time and secrets locally with the parent helper, then reboot:
   ```bash
   sudo unscroll-ouder
   ```

After booting, the child account logs in automatically and the app starts full screen
(`cage` with the `foot` terminal). There is no desktop, no browser and no free shell.

## Updates

- **Releasing a new version:** bump the number in `VERSION` and push to `main`. GitHub Actions runs the tests, builds the app for 386, amd64, arm64 and arm (with a `sha256` file per binary) and creates the release.
- A number with a dash (`0.2.0-test`) becomes a pre-release. It only goes to devices with `KANAAL="test"` in `/etc/unscroll/update.conf`.
- Devices check for a new release every 15 minutes (`unscroll-update.timer`), verify the checksum and that the new binary starts, then install it. The previous version is kept.
- If the repository is private, put a fine-grained read-only token in `/etc/unscroll/geheimen.env` (the parent helper asks for it).

## Settings

| File | Owner | Contents |
|---|---|---|
| `~/.config/unscroll/instellingen.json` | the child | name, buddy, face, colour theme, language |
| `/etc/unscroll/ouders.yaml` | parents (root) | quiet time, PIN, maximum volume, ntfy topic, AI buddy limits |
| `/etc/unscroll/update.conf` | parents (root) | repository and update channel |
| `/etc/unscroll/geheimen.env` | parents (root) | tokens and API keys, never in git |

## The AI buddy (phase 4)

The buddy is a helper, not a friend: it only speaks when asked and helps the child think
instead of thinking for them. Limits depend on the kind of use:

| Mode | How | Default limit |
|---|---|---|
| Homework coach and quizzing | A session about one assignment: try first, hints in steps, a worked example with different numbers, ending with "what did you learn?" | 2 sessions a day, 40 turns per session |
| Write a story together | Take turns writing, saved in the writing nook | 1 session a day |
| Free questions | Curiosity: "how does it work?" | 15 a day |
| Overall | | 45 minutes a day, a break after 20 minutes, closed during quiet time |

Safety: personal details are filtered out before anything is sent, every question and answer
gets a second suitability check, heavy topics are referred to the parents, and a "is this
right?" button teaches that AI can be wrong.

Parents set the limits with `sudo unscroll-ouder`. The defaults and the buddy's instructions
are part of the app and are tuned through updates as we learn from real use.

## Passwords and keys

**Secrets never go into this repository.** PIN, passwords, usernames, tokens and API keys are
set locally on the device with the parent helper:

```bash
sudo unscroll-ouder
```

It writes to `/etc/unscroll/ouders.yaml` and `/etc/unscroll/geheimen.env` (readable only by
root and the app). Git only contains example files with empty values. GitHub Actions checks on
every push that no real settings or keys ended up in the repository.

## Development

```bash
cd app
go test ./...
go run .                      # runs in your own terminal
UNSCROLL_OUDERS=../config/ouders.example.yaml go run .
CGO_ENABLED=0 GOOS=linux GOARCH=386 go build -o unscroll .
```

The app is written in Go with [Bubble Tea](https://github.com/charmbracelet/bubbletea) and
[Lip Gloss](https://github.com/charmbracelet/lipgloss), so it ships as a single small binary
that runs well on old 32-bit hardware. Some file names and code identifiers are still Dutch,
since the project started in a Dutch family; translations of the app are welcome.

## Layout

```
app/        the terminal app (Go)
scripts/    unscroll-sessie (kiosk start), unscroll-update (updater), unscroll-ouder (parent helper)
systemd/    timer and service for the updater
config/     example settings and the terminal configuration
docs/       clickable mockup
install.sh  installer for a fresh Debian 12
VERSION     the version that GitHub Actions releases
```
